# `components/`

| Directory | Contains |
| --- | --- |
| `ui/` | shadcn/ui primitives, owned in-repo |
| `charts/` | Recharts wrappers — `CashFlowChart`, `TrendChart`, `CategoryBreakdown` |
| `upload/` | `UploadDropzone`, `ColumnMapper`, validation feedback |
| `report/` | `ScoreDial`, `PillarBar`, `MetricCard`, `InsightCard`, `RecommendationCard`, `FundingReadinessPanel` |
| `marketing/` | Landing page sections |

Tokens, formatting rules, and voice: [docs/DESIGN_SYSTEM.md](../docs/DESIGN_SYSTEM.md).

Non-negotiables: WCAG 2.1 AA, tabular numerals for every figure, colour never the sole carrier of meaning, and every view usable at 375px.
